# 지표 정의

각 지표의 계산식은 [equations.md](equations.md)에 있다.

## 답변 3분류 (판정, 295문항)
| 분류 | 정의 |
|---|---|
| 정답 | 결론이 맞고, 쓴 내용이 전부 근거 안에 있다 |
| 환각 | 근거에 없거나 근거와 어긋나는 내용이 하나라도 있다 (결론이 틀린 경우 포함) |
| 무응답 | 질문에 대한 판단(가부·방향)이 담기지 않았다 |

세 비율의 합 = 100%.

### 환각 4유형 (RAGTruth)
| 코드 | 이름 | 예 |
|---|---|---|
| EC | Evident Conflict | 근거 "4개사 이하" → "5개사 가능" |
| SC | Subtle Conflict | 근거 "10년 이상" → "정확히 10년은 제외" |
| EB | Evident Baseless | 존재하지 않는 조항 번호·금액 |
| SB | Subtle Baseless | "사전에 협의하시기 바랍니다" 같은 근거 밖 조언 |
한 답변에 여러 유형이 있으면 가장 심한 것 하나(EC > EB > SC > SB).

### 무응답 4유형
근거 반복 · 절차 서술(결과값 없음) · 파편(조각) · 질문 반복

## 파생
**정답 안정도** = 지시문 5종 정답률의 평균 − 표준편차. 운영 중 지시문을 바꿔도 대체로 보장되는 수준.

## 규칙 기반 (295문항 자동)
| 지표 | 정의 | 선정 사용 |
|---|---|---|
| 형식 준수 | 지시한 출력 형식(`답변:`/`근거:`)을 지킨 비율 | 아니오 — 운영 프롬프트 형식과 다름 |
| 인용 정확도 | 적은 근거 번호 중 제공 범위 안인 비율. 대괄호 번호와 숫자만 나열된 `근거:` 줄만 인용으로 인정. 번호가 없으면 0 | 예 |
| 수치 재현 | 기대답의 숫자(2자리 이상, 날짜는 한 덩어리)가 답변에 나온 비율. 기대답에 숫자가 있는 58문항 | 아니오 — 문자열 대조 |
| 원문 복사 | 답변에 근거 문장이 60자 이상 그대로 들어간 비율 | 아니오 — 운영은 짧은 원문 인용을 요구 |

## 운영
| 지표 | 조건 |
|---|---|
| 응답 p50 / p95 | 워크스테이션 Xeon CPU, 문맥 24,576, 스레드 12, 30문항 (모델 간 비교용. 도입 노트북은 약 0.7배) |
